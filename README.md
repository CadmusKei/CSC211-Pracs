# CSC211 Data Structures & Algorithms Repo

## Overview

This repository contains a collection of **Java projects and exercises** built as part of university coursework to practice and understand fundamental data structures and algorithms.

The goal of this repository is to:

- Implement **data structures from scratch**  
- Explore core **algorithmic patterns**  
- Analyze **time and space complexity** experimentally by timing the implementations  

---

## Repository Structure

The repository is organized by topic/project:

- **Anagrams** – Exercises involving string manipulation and anagram detection  
- **Hashing** – Implementation and analysis of hash-based data structures  
- **Heaps** – Building and testing heaps from scratch  
- **JavaAlgos** – Collection of common Java algorithm implementations  
- **MCS** – Project exploring Maximum Contiguous Subarray problems  
- **MergeSort** – Implementation and timing analysis of Merge Sort  
- **Practice** – Miscellaneous algorithm and data structure exercises  
- **Shuffling** – Implementation of array/list shuffling algorithms  
- **TimeSortingAlgos** – Comparing the runtime and efficiency of different sorting algorithms  
- **etc**
---

## Purpose

For each project, we focus on:

1. **From-scratch implementation** – coding the data structure or algorithm without using built-in Java classes  
2. **Experimental analysis** – measuring the **time and space complexity** by running and timing our implementations  
3. **Learning and comparison** – understanding how different approaches scale with input size and data distribution
